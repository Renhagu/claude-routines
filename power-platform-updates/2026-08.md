# 2026年8月 Power Apps アップデートまとめ

> 調査期間：2026年7月〜8月  
> 作成日：2026年8月13日

---

## Power Platform 関連

### Power Apps の主な変更

- ⭐ **データグリッド モダンコントロール GA**：Canvas Appsでデータグリッドのモダンコントロールが正式リリース。Fluent UIベースで高パフォーマンス・高密度なテーブルビューを提供。データソース接続時に列を自動生成し、Power Fxで各列をカスタマイズ可能。
- **モダンフォームの機能強化**：改善されたデータカード（モダンコントロールベース）が有効化。フィールド値・デフォルト・数式の評価が正確になり、`ResetForm`やDate Pickerのリセット動作が修正された。
- **Studio のモニタリング・コード管理ツール強化**：大規模・複雑なアプリを扱うメーカーやAdmin向けに、可視性とルーティング制御が向上。
- **Canvas Apps のオフライン強化**：FetchXMLによる高度なオフラインプロファイル設定、カスタムブランドアプリでのプッシュ通知が可能に。リアルタイムDataverseアクセス（オンラインモード）との並列対応も実現。

### Dataverse の主な変更

- ⭐ **Dataverse MCP Server の拡張**：DataverseプラグインがClaude・Cursor・GitHub Copilotのコーディングエージェントマーケットプレイスで利用可能に。15種のMCPツールを提供し、エージェントとデータプラットフォーム間の型付き・ガバナンス可能なコントラクトとして機能する。
- ⭐ **Work IQ APIの提供**：Dataverse Work IQ APIとMCPサーバーにより、開発者がビジネスエージェントをカスタムアプリに組み込み・拡張可能に。DataversePython SDKも提供され、ラピッドプロトタイピングに対応。
- **Data Hub と Storage Advisor**：Adminがテナント全体のデータ消費を可視化・最適化するためのインサイトと推奨機能が追加。
- **Microsoft Purview連携変更**：2026年5月以降、DataverseからPurviewへ送信される監査イベントに変更前後のフィールド値が含まれなくなった（監査イベント自体は継続送信）。

### Power Automate の主な変更

- ⭐ **デスクトップフロー バージョン比較**：組み込みバージョン管理にバージョン比較機能が追加。サブフロー・アクション・変数・UI要素・画像を横並びで比較可能。バージョンはDataverseに最大12ヶ月保存。
- ⭐ **AI セルフヒーリング**：UIアクションが失敗した場合、AIが代替要素を使って自動リトライ。UI要素の変更に自動適応し、手動修正・IT介入を削減。
- **「Power Appを実行」アクション**：デスクトップフローからPower Appを直接開き、ネイティブの通信チャネルを確立する新アクション。
- **Power Automateモバイルアプリ（iOS/Android）非推奨化**：2026年8月31日より非推奨。
- **Microsoft Purview 連携**：アイテムが保持期間終了時にPower Automateワークフローを開始できるようになった（廃棄承認・アーカイブ移動など）。
- **VisioデスクトップでのPower Automate統合非推奨化**：2026年7月14日より非推奨。

### Power BI の主な変更

- ⭐ **モダンビジュアルのデフォルト化（テーマ連動）**：書式設定ペインから現在のテーマを直接カスタマイズ可能。色・パレット・デフォルト書式を一度設定すれば全ビジュアルとページに適用。
- ⭐ **条件付き書式のGA拡大**：折れ線・棒・縦棒・円・ドーナツグラフの凡例への条件付き書式が一般提供に。
- **Desktop Bridge Preview**：外部アプリやエージェントがPower BI Desktopと直接連携できる軽量ローカルサーバー。レポート状態確認・スクリーンショット・ファイルリロード・安全なローカルAPIをサポート。
- **Webモデリングでモデルオプションダイアログ提供**：Power BI Desktop不使用でもWeb上でモデルレベルの設定変更が可能に。
- **組織アプリ（Org Apps）強化**：オーディエンス・ブックマーク・PowerPointストーリーテリングの追加、管理APIの新設。
- **TMDL ViewがWebに提供**：TMDLビューがWebモデリングでも利用可能に。
- **重要なお知らせ**：2026年10月以降、2026年3月以前のPower BI Desktopを使用しているユーザーはOneDriveおよびSharePointへのファイル保存・共有が不可に。

### Power Pages の主な変更

- ⭐ **統合認可モデルGA**：WebロールとDataverseセキュリティロールを統合する統合認可モデルが2026年8月に正式リリース。権限の不整合削減・監査の簡素化を実現。移行計画が必要。
- **クライアントAPI GA**：Power Pagesコンポーネント向けクライアントAPIが2026年7月に正式リリース。
- **AIコーディングツールGA**：サイト構築向けAIコーディングツールが2026年6月に正式リリース。手動コーディングを削減し、迅速な開発を支援。

## Microsoft 365 / Azure 連携

### SharePoint・Teams・Excel との連携に関する変更

- ⭐ **SharePoint Copilot Apps パブリックプレビュー**：AIファーストなSharePointエクスペリエンスが利用可能に。カスタムグループ接続済みSharePointサイトのカタログ管理、Teams内のSharePoint強化、Copilot機能が追加。
- **SharePointリストをCopilot Studioエージェントに直接統合**：データ移動や複雑な統合なしに、リストデータでAI回答をグラウンディング可能に。
- **SharePoint Framework（SPFx）ロードマップ更新**：2026年7月にSPFxのロードマップが更新。
- **Power Platform データのAzure Resource Graph対応**：Power Platform for Admins V2コネクタ・在庫APIに加え、Azure Resource Graphを通じてPower Platformデータをクエリ可能に。テナント全体の分析が単一クエリで実現。
- **Teams Town Hallの音声・映像オフロード（VDI対応）**：VDI環境でのTown Hall参加者向けにメディアストリームをローカルデバイスにオフロード。

### Azure との連携に関する変更

- **Power Platform in Azure Resource Graph**：テナント全体のPower Platformリソースをプログラマティックにクエリ・分析可能。
- **Dataverse Python SDK提供**：Azureでのラピッドプロトタイピングとスクリプティング向けネイティブ開発エクスペリエンスを提供。

## AI・Copilot 機能

### Power Apps における Copilot・AI Builder の新機能

- ⭐ **モデル駆動型アプリ内Copilot Chat GA（フォーム・グリッド対応）**：アプリ内のフォームやグリッドに基づいたCopilot Chatエクスペリエンスが2026年7月に一般提供。カスタムUXのプレビューも開始。Microsoft 365 CopilotのResearcher・Analystエージェントや、カスタムCopilot Studioエージェントも活用可能。
- ⭐ **Agent Feed GA**：モデル駆動型アプリ内のAgent Feed（エージェントのアクティビティを監視するスーパービジョンインボックス）が2026年5月4日にGA。「完了」と「要対応」で分類されたタスクボードとして機能。2026年5月1日以降、Power Apps MCPサーバーを使用するエージェントのみサポート。
- ⭐ **行サマリー（Row Summaries）の拡充とガバナンス強化**：モデル駆動型アプリのレコードサマリーが拡張。Power Platform 管理センターの「Copilot > 設定 > Power Apps > サマリー > 行サマリー」で制御可能。
- **アプリスキル（App Skills）GA**：データ入力・探索・可視化・要約などのビルトインAIスキルが一般提供に。
- **ジェネレーティブページの拡大**：Power AppsでのAI生成ページが可用性・柔軟性ともに向上。
- **Copilot Studio マルチエージェントオーケストレーション**：複雑なエンドツーエンド自動化を実現するマルチエージェントオーケストレーションが拡充。高度なガバナンス・評価機能も追加。
- **Power Platform ガバナンスのAI強化**：エージェントセキュリティ向けAdmin制御、Copilot Studioでのリアルタイムリスク評価、テナント監視・修復を自動化するAI Govエージェントが追加。
- **Power Automate のエージェント機能**：Desktop Flowsでのエージェントベースの自動化、コパイロット駆動アクション、フロー最適化エージェントが追加。

## モデル駆動型アプリ（詳細）

- ⭐ **モダンUIのデフォルト化（強制適用）**：2026 Wave 1より、新しいルック（New Look）が全ユーザーに強制適用。モダンなヘッダーとナビゲーションがGAに。
- ⭐ **Agent Feed（エージェントフィード）**：アプリ内に組み込まれたエージェント監視インボックス。エージェントのアクティビティを「完了」と「要対応」に分類して管理。Power Apps MCPサーバーとの統合必須（2026年5月以降）。
- ⭐ **アプリ内Copilot Chat（フォーム・グリッド連携）**：ユーザーがアプリ内でデータに関する質問・推論が可能。アプリを離れることなくドキュメントや通信からのインサイト取得、Researcher/Analystエージェント活用も可。
- ⭐ **行サマリー（Row Summaries）**：レコード詳細画面でAI生成のサマリーを表示。チームがデータを素早く理解・対応できるよう支援。管理センターからの制御が可能。
- **検索機能の改善**：より高速な結果、精度の高いマッチングロジック、強調表示の改善。
- **カスタムUX for Copilot Chat（プレビュー）**：Copilot ChatのカスタムUXがプレビュー提供開始。
