# 2026年7月 AIアップデートまとめ（2026年6月の動向）

> 調査日: 2026-07-02

## [2026年6月] AIアップデートまとめ

### Anthropic（Claude）

- ⭐ **Claude Sonnet 5 リリース**（6月）: 推論・ツール使用・コーディング・自律タスク処理が大幅強化。Claude Code のデフォルトモデルとなり、1Mトークンのコンテキストウィンドウを搭載。8月31日まで $2/$10/Mtok のプロモーション価格。
  - https://releasebot.io/updates/anthropic/claude
- ⭐ **Claude Fable 5 発表**（6月9日）: Opus クラスを超える新しい「Mythos」クラスの最上位モデルとして登場。
  - https://www.anthropic.com/news
- **Fable 5 輸出規制解除**（6月30日）: 7月1日より Claude Platform・Claude.ai・Claude Code・Claude Cowork で全世界提供開始。
- **Claude in Microsoft Foundry GA**: Microsoft Foundry での Claude 利用が正式提供開始。
- **Dynamic Workflows（研究プレビュー）**: Claude Code CLI・Desktop・VS Code 拡張の Max/Team/Enterprise プラン、および Claude API・Amazon Bedrock・Vertex AI・Microsoft Foundry で利用可能に。
  - https://releasebot.io/updates/anthropic/claude-code
- **モデル廃止**（6月15日）: `claude-sonnet-4-20250514` と `claude-opus-4-20250514` が API から削除。
  - https://enterprisedna.co/resources/news/anthropic-claude-june-15-retirements-billing-2026/
- **課金体系変更**（6月15日）: Claude Agent SDK・ヘッドレス Claude Code・Claude Code GitHub Actions等がサブスクリプション枠外となり、API レートで月額課金へ移行。
  - https://www.pravinkumar.co/blog/claude-june-15-billing-change-explained-2026

### OpenAI（ChatGPT）

- ⭐ **GPT-5.5 Instant パーソナライゼーション強化**（6月9日）: ChatGPT のデフォルトモデルが更新。回答の正確性・簡潔さが向上し、GPT-5.3 Instant 比でハルシネーション 52.5% 削減。
  - https://openai.com/index/gpt-5-5-instant/
- **GPT-5.6 Sol プレビュー**（6月28日）: 次世代モデルの先行公開。
- **Codex Remote 全プランで GA**: Mac/Windows ホストに接続しスマートフォンから作業確認・承認が可能に。
  - https://releasebot.io/updates/openai/chatgpt
- **音声テキスト変換モデル更新**: 全プランで新しい音声認識モデルを展開、多言語・多アクセントの精度が向上。
- **Memory Sources 導入**: レスポンスのパーソナライズに使用されたコンテキストを可視化・管理できる新機能。
- **モデル廃止**: GPT-5.2 系（6月12日）・GPT-4.5（6月26日）が ChatGPT から削除。
  - https://help.openai.com/en/articles/6825453-chatgpt-release-notes
- ⭐ **Broadcom と連携した推論チップ発表**（6月24日）: LLM 最適化の専用推論半導体を共同開発。
  - https://www.kunalganglani.com/blog/chatgpt-biggest-upgrade-developers-june-2026

### Google（Gemini）

- ⭐ **Gemini Spark macOS 展開**（6月）: デスクトップファイル・アプリを横断して重い作業を自動化。Canva・Dropbox・Instacart・OpenTable・Zillow Rentals と統合。
  - https://blog.google/innovation-and-ai/products/gemini-app/gemini-spark-updates-june-2026/
- **Gemma 4 12B リリース**: ノートPC 上でローカル動作する 16GB RAM 対応の軽量モデル。視覚とネイティブ音声処理を統合したアーキテクチャ。
  - https://blog.mean.ceo/google-gemini-news-june-2026/
- **Gemini 3.5 Live Translate**: リアルタイム翻訳機能の新バージョン。
- **Gemini in Chrome on Android**: Android Chrome にGemini 統合（Nano Banana・auto browse）。4GB RAM 以上の端末から英語優先で展開。
  - https://blog.google/innovation-and-ai/technology/ai/google-ai-updates-june-2026/
- **マルチモーダルファイル検索**: `gemini-embedding-2` モデルにより画像のネイティブ埋め込みと検索が可能に。
  - https://ai.google.dev/gemini-api/docs/changelog
- **Gemini Intelligence for Android**: Android に常時稼働するプロアクティブ AI 機能を搭載。
  - https://blog.google/products-and-platforms/platforms/android/gemini-intelligence/
