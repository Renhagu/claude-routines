# 2026年7月 AIアップデートまとめ

## Anthropic（Claude）

- ⭐ **Claude Opus 5 リリース**（7月24日）：フロンティア級に近い性能を従来の約半額で提供する新モデル。プロアクティブな動作が特徴
- **Cowork のモバイル・Web 展開**：セッションとファイルをデバイス間で共有。バックグラウンド作業・スケジュールタスク・モバイル承認に対応
- **「Reflect」ダッシュボード導入**：Claude 利用状況（議題・パターン・タスク種別）を可視化する組み込みダッシュボード
- ⭐ **MCP 2026-07-28 仕様サポート拡充**：ステートレスコア、強化された OAuth / OIDC 認証、バージョン管理拡張機能（Apps / Tasks）、埋め込み UI・企業管理認証・オブザーバビリティ・プライベートネットワークトンネルを含む新コネクタ機能
- **Cognizant との提携拡大**：エンタープライズ顧客への Claude 展開を強化
- **量子暗号研究**（7月28日）：Anthropic が HAWK（耐量子署名方式）の弱点発見に関する研究を公開

## OpenAI（ChatGPT）

- ⭐ **GPT-5.6 ファミリー発表・GA**（7月9〜10日）：Sol（フラッグシップ）・Terra（ミッドレンジ）・Luna（廉価版）の3層構成。Luna は価格を80%削減
- **コンテキストウィンドウ拡大**：Enterprise プランで最大 1.5M トークン（GPT-5.5 の 400K の3.75倍）
- ⭐ **ChatGPT Work 公開**（7月9日）：チームツールのコンテキストを統合し、メモや下書きを完成品に仕上げる新プロダクト。全プランに提供
- **SynthID 音声透かし**（7月31日）：ChatGPT Voice と API で生成した音声に SynthID 透かしを付与。公開検証ツール・API も提供
- **WhatsApp 連携復活**（7月13日）：欧州経済領域でアカウント不要の ChatGPT WhatsApp 利用が再開
- **Plugin Directory への移行**：App Directory を廃止し Plugin Directory へ一本化。Work・Codex などのプラグインを提供
- グループチャット新規作成機能を終了（既存のグループチャットは継続利用可）

## Google（Gemini）

- ⭐ **Gemini 3.6 Flash 投入**：日常タスク向けにアップグレードされた Flash モデルを新たにリリース
- **AIエージェント向け新モデル3種**：大規模エージェント構築を支援する新モデル群を発表
- **Gemini Robotics ER 2**：ロボットが推論・協調・実世界タスクを解決するための新ロボティクスモデル
- **Google Docs の Gemini 強化**：関連ビジュアルサマリー生成、スタイル調整、複数ビジュアル一括更新をアプリ内で実現。対応言語を11言語追加（中国語・オランダ語・マレー語・ヘブライ語・ポーランド語・トルコ語・チェコ語・インドネシア語・スウェーデン語・デンマーク語・ノルウェー語）
- ⭐ **動画生成品質向上**：Omni Flash モデルによるテキスト描写・物理シミュレーション・リアリティ向上。カラーグレーディング修正、アニメ風スタイル変換、背景音除去に対応
- **エンタープライズデータリージョン拡充**：Gemini アプリに EU / US の地理的データ処理コントロールを追加
